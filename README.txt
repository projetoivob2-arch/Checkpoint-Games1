# Checkpoint Games
Blog de games com cinco páginas: Home, Hardware, Reviews, E-sports e Contatos.

## Como publicar no GitHub Pages
1. Extraia o arquivo ZIP no computador.
2. No repositório GitHub, entre em Add file > Upload files.
3. Envie todos os arquivos extraídos diretamente para a raiz do repositório (não envie apenas o ZIP e não crie uma pasta extra).
4. Clique em Commit changes.
5. Em Settings > Pages, selecione Deploy from a branch, branch main e pasta /(root), e salve.
6. Aguarde a publicação do GitHub Pages.

As ilustrações são SVGs embutidos no próprio HTML, portanto não dependem de uma pasta assets nem de arquivos de imagem externos.
O formulário de contato prepara um e-mail para projetoivob2@gmail.com usando o aplicativo de e-mail do visitante; para envio automático sem abrir e-mail, seria necessário um serviço/backend.
